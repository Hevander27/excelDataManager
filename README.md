# Excel VBA Macros for Data Analysis and Reporting

A collection of VBA macros designed to enhance data analysis, visualization, and reporting in Excel. These tools automate common tasks for data analysts and business users working with Excel data.

## Features

### Data Formatting and Analysis

- **FormatCellsThresholds** - Apply color formatting to cells based on user-defined thresholds, making it easy to identify values outside specified ranges
- **HighlightNormalDistribution** - Visually identify statistical outliers by highlighting values that fall outside a specified number of standard deviations from the mean

### Advanced Analytics

- **PerformDBSCAN** - Perform density-based spatial clustering (DBSCAN) on selected data columns to identify patterns and outliers in your data
- **CombinedTableOperations** - Extend Excel tables based on date ranges from SQL scripts and append data from external connections

### Automated Reporting

- **Pivot_Table_AgentCalls** - Generate comprehensive reports on agent calls with PivotTables, charts, and slicers for interactive data exploration
- **Pivot_Table_Ratio** - Create detailed reports on agent call ratios with visual trend analysis and filtering capabilities

## Use Cases

- Business intelligence and data analysis
- Performance monitoring and reporting
- Outlier detection and statistical analysis
- Data integration and synchronization with external sources
- Interactive dashboard creation

## Compatibility

These macros are designed to work on both Windows and Mac versions of Excel, with cross-platform compatibility considerations built into select functions.
